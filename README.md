# 大肥鱼 · 文生图提示词工坊

一个**纯静态、零后端、零大模型 API** 的中文文生图提示词工具。输入一句中文（可夹英文），用本地词典、规则和模板拆成六个可校对的中英对照框，再按 SDXL / ComfyUI 的习惯组装成可直接粘贴的英文正面与负面提示词。

- **17,000+ 条中英规范词条**，支持中文/英文/同义词搜索
- 搜索词库、已填框内容、收藏和历史
- 一键收藏当前想法、六个框与最终提示词，可再次打开重新生成
- 自动保存最近 30 条生成历史
- 生成后打开完整中英对照预览，预览里也能复制
- 无需登录、无需构建、不上传内容
- 直接双击 `index.html` 即可使用
- 兼容 Lustify Endgame（SDXL）和 ComfyUI
- 手机窄屏可用，复制成功有提示

## 本地打开

最简单的方式：

1. 找到本目录的 `index.html`
2. 双击用现代浏览器打开（Safari / Chrome / Edge 均可）

也可以在本目录启动一个本地静态服务器（可选，不是必需）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

项目没有 npm 安装步骤、没有打包步骤，所有脚本都是普通 `<script>`，所以直接以 `file://` 打开也能工作。

## 使用方法

1. 在「整体想法」里写中文，例如：
   > 傍晚街边，短发女人穿米色风衣站着，侧脸看向远处，柔和自然光，电影感
2. 点「补全并填入各框」。
3. 检查六个框：
   - 人物与外貌
   - 服装与造型
   - 姿态与动作
   - 场景与背景
   - 光线与镜头
   - 画风与质感
4. 任意修改中文或英文。词典能对齐时会同步另一侧；对不上的原文会保留并给出温和提示。
5. 点「生成提示词」。
6. 复制正面 / 负面英文；下方同时显示中文对照。
7. 点「预览完整对照」可在全屏预览中检查正面 + 负面的完整中英对照，并直接复制。

规则补上的光线、镜头、画风等内容会显示琥珀色「补全」标记，并列出中文、英文和补全原因。修改或删除后标记会自动更新。

### 搜索、收藏、历史

- **搜索**：页面中部的搜索框会同时搜索：
  - 内置词库（中文、英文、同义词）
  - 六个框里当前填写的内容
  - 收藏夹和历史记录
  - 词库结果可以直接点「填入人物与外貌 / 服装与造型…」加入对应框
- **收藏当前**：保存当前想法、六个框、正负面结果和补全标记。收藏会显示在「收藏夹」，可打开、重新生成或删除。
- **历史**：每次生成后自动保存最近 30 条记录，可回看、打开、继续编辑和删除。
- 收藏与历史保存在浏览器 `localStorage`；清理浏览器数据会丢失。若浏览器禁用本地存储，功能仍可在本次页面中使用，并会给出提示。

## 部署到 GitHub Pages

当前不需要真的创建仓库，但以后可以直接这样上线：

1. 新建一个 GitHub 仓库，把本目录内容放到**仓库根目录**。
2. 推送到默认分支（例如 `main`）。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选 `main`，目录选 `/ (root)`，保存。
6. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

如果希望把站点放在 `/docs` 目录，把 `index.html`、`styles.css`、`js/` 整体移入 `docs/`，然后在 Pages 里选择 `/docs` 即可。所有资源都是相对路径，两种方式都能用。

仓库里的 `logs/` 是开发日志，已加入 `.gitignore`，不需要发布。

## 词典与算法

词典规模（当前版本）：

- **17,523 条规范词条**
- **1,467 条人工词条**
- **16,056 条组合词条**
- **35,469 个中文说法 / 同义词**
- **19,287 个英文说法 / 同义词**
- **22 个类别**

组合词条不是乱拼：先维护准确的基词，再按「颜色 × 服装 / 鞋履 / 配饰」「材质 × 服装」「图案 × 服装」「发色 × 发型」「时间 / 天气 × 场景」「光质 × 光型」「焦距 × 景别」生成规范搭配。生成时跳过已有手工词条、跳过明显矛盾组合，并且所有英文都来自已有规范译法。

词典按人物类型与年龄体态、五官外貌、发型发色、眼睛、表情、妆容、服装、配饰、鞋履、材质、图案、颜色、姿态动作、场景、时间、天气、光线、镜头构图、画风、质感、质量词、负面词等类别组织。同义词指向同一个规范译法，英文尽量采用生图提示词惯用表达（如 `cinematic lighting`、`soft natural light`、`film grain`、`50mm`、`shallow depth of field`）。

处理流程：

1. **切句**：中文标点、英文逗号、顿号、换行都会成为边界。
2. **按提示词切分**：识别「穿着 / 戴着 / 站在 / 坐在 / 背景是 / 光线是 / 镜头是 / 风格是」等模式；「穿米色风衣的女人」这类定语结构不硬切。
3. **分类**：用最长词匹配计分，结合引导词、主体词和上下文（颜色在光线/场景/服装中的归属不同）归入六个框。
4. **保底**：分不清的内容按关键词放到最相近的框；完全没词典命中的原文原样保留。
5. **补全**：只在缺失时补默认光线、镜头和基础真实摄影质感，并且逐条记录为「补全」。
6. **组装**：人物 → 服装 → 姿态 → 场景 → 光线镜头 → 画风 → 少量质量词，用逗号分隔。
7. **负面**：通用 59 项负面词，并根据正面明确要求（浅景深、胶片颗粒、全身照、高饱和等）自动移除冲突项。

## 测试

核心算法测试不依赖任何第三方包：

```bash
node tests/core.test.js
```

会检查词典规模、双向翻译、六框拆分、补全标记、组装顺序、负面冲突过滤、复杂命中、未收录内容保留等 12 项。

开发时另外使用过 jsdom 做搜索 / 收藏 / 历史 / 预览 / 复制的交互回归，用 macOS WKWebView 在 1400px、390px、360px 宽度做真实渲染截图检查（这些测试工具不随项目发布，页面本身不依赖它们）。

## 隐私与边界

- 没有网络请求，没有统计脚本，没有账号，没有后端。
- 输入内容默认只存在于当前页面内；收藏和历史由用户主动使用「收藏当前」或「生成提示词」后写入浏览器本地 `localStorage`，不会上传。
- 清除浏览器数据会删除本机收藏和历史。
- 这是一个**规则 + 词典**工具，不做语义大模型推理；复杂长句、隐喻、方言、冷门专有名词可能拆得不够理想。这类词会保留原文并提示，不会瞎编错译。
- 17,000+ 条词条中大部分是组合词条，适合覆盖常见颜色、材质、图案和场景搭配；极冷门的现实品牌、特定历史装备、亚文化服饰或虚构角色仍需自行补词。
- 默认补全偏真实摄影、克制中性；不会编造人物身份、服装或剧情。
- 工具不提供内容安全审核，最终提示词及生成结果由使用者自行负责。

## 自定义

- 增加词条：编辑 `js/lexicon.js` 中的 `GROUPS` 或 `EXTRA_GROUPS`，格式为 `[中文规范词, 英文规范译法, 中文同义词[], 英文同义词[]]`。
- 调整组合扩充：编辑 `js/lexicon.js` 后半部分的组合数组与 `addGenerated` 逻辑。
- 调整默认补全：编辑 `js/complete.js`。
- 调整质量词：编辑 `js/assemble.js`。
- 调整负面词顺序与冲突规则：编辑 `js/negative.js`。
- 调整界面：`styles.css` 顶部集中定义了颜色、圆角和字体变量。
